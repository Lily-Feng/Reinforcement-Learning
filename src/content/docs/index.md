## What this is

Notes I am writing as I work through reinforcement learning, arranged as a book
rather than a pile of files. Every topic gets an explanation, the equations, a
worked example, and an interactive demo you can actually poke at.

Chapters run from easy to complex. Bandits before MDPs, because bandits have no
state. Dynamic programming before Monte Carlo, because a known model is easier
than a learned one. Function approximation late, because everything before it
assumes a lookup table.

Start with [Getting started](/Reinforcement-Learning/getting-started/), or jump
straight to
[Multi-armed bandits](/Reinforcement-Learning/chapters/02-multi-armed-bandits/).
